# India-Voter-Turnout-Analysis-2024

## Overview 
This project examines the determinants of voter turnout across Indian states in the 2024 Lok Sabha elections using econometric methods in R. The analysis uses cross-sectional data and applies Ordinary Least Squares (OLS) regression alongside diagnostic testing and HAC (Newey–West) robust standard errors.

## Key Methods

1. Ordinary Least Squares (OLS) Regression
2. Shapiro-Wilk & Jarque-Bera Normality Tests
3. Breusch-Pagan Heteroskedasticity Test
4. Variance Inflation Factors (VIF)
5. HAC (Newey–West) Robust Standard Errors
6. Residual Diagnostics & Visualization using ggplot2
